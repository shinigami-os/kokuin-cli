"Booted" is a feeling more than an event: the desktop appears, but the disk keeps
working and the first application opens slowly. kokuin defines **ready** as:

- the session shell (panel, bar, desktop shell) is running, and
- when recording live, the CPU and disks have stayed quiet for a moment.

When rebuilding a boot afterwards, only the first condition can be checked: the time
is then the start of the shell.
